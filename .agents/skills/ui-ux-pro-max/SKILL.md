# UI/UX Pro Max Skill

When building or modifying user interfaces, apply the highest standards of modern web design to create a "Pro Max" experience that wows the user at first glance.

## 1. Rich Aesthetics
- **Color Palettes**: Never use generic colors (plain red, blue, green). Use curated, harmonious color palettes (e.g., HSL tailored colors) and sleek dark modes. Use smooth, modern gradients where appropriate.
- **Typography**: Utilize modern typography (e.g., Google Fonts like Inter, Roboto, Outfit or system sans-serif like SF Pro). Avoid browser default fonts.
- **Glassmorphism**: When suitable, apply backdrop filters (`backdrop-filter: blur()`) with semi-transparent backgrounds to create depth.
- **Shadows & Depth**: Use layered, soft box shadows to give floating elements a premium, tactile feel.

## 2. Dynamic Interactions
- **Micro-animations**: Add subtle transitions on hover, focus, and active states. All interactive elements (buttons, links, inputs) must respond visually (e.g., scale up slightly, color shift, shadow expansion).
- **Transitions**: Use smooth CSS transitions (`transition: all 0.2s ease-in-out;`) to make the interface feel responsive and alive.
- **Loading States**: Avoid static loading screens. Use skeletons or elegant spinners.

## 3. Component Excellence
- **No Placeholders**: If an image or icon is needed, use realistic or generated images (via tools) or modern icon libraries (like Lucide, Heroicons).
- **Spacing**: Use a consistent spacing scale (e.g., multiples of 4px or 8px) for margins and padding to ensure a balanced, breathable layout.
- **Border Radius**: Apply consistent rounding to corners (e.g., 8px, 12px, or fully rounded pills for specific buttons) to soften the interface.

## 4. Professional Implementation
- **Custom CSS / Tailwind**: Whether using Vanilla CSS or Tailwind, ensure utility classes or CSS rules are consistently applied. (Confirm Tailwind version with the user if using it).
- **SEO & Accessibility**: Always use semantic HTML5 elements. Ensure proper contrast ratios and aria-labels for accessibility.

**Goal**: Deliver a polished, production-ready interface that feels expensive, state-of-the-art, and significantly better than a Minimum Viable Product.
